# 综合测评工作台

本机运行的本科生综合测评网页系统。学院名称可配置，当前规则来自用户提供的《北京语言大学本科生综合素质测评办法》（校学字〔2022〕28 号）。默认载入桌面的“文学院25-26附加分大礼包”，原文件不修改。

## 启动

```bash
bash start.sh
```

访问 http://127.0.0.1:8765 。有 Codex 配套 Python 环境时启动脚本自动使用；其他电脑先安装 Python 3.10+：

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
bash start.sh
```

`npm start` 也可启动。前端无需安装依赖，无外部字体/CDN、构建步骤或联网服务。

首次启动且数据库为空时自动导入桌面材料，后续通过网页导入。建立独立测试工作区：

```bash
bash start.sh --no-seed --db .local/test-workspace.sqlite3 --port 8766
```

本版一次维护一个学年批次，默认学年标签为 2025-2026。

## 功能

- **班级 / 学生维护**：新增、编辑、停用与恢复，学号唯一。可从现有申报生成名册，跳过身份冲突、缺失和明显研究生记录；班级采用第一条来源写法，需人工核对。名册按学号统一当前院系和班级，姓名冲突进入审核。没有申报的在册学生也出现在汇总中。停用名册不删除申报。
- **批量导入与类别预览**：多文件、多工作表 `.xlsx`；按“表内活动性质 → 工作表名/简称”识别。未知、勾选冲突的工作表必须手动指定类别后才能导入；匹配结果也可调整。示例/说明页、空行和仅序号占位行跳过。
- **来源追溯**：保留文件名、工作表、原始行号与原分值；原始记录与当前审核记录分开保存。文件哈希防止重复导入。
- **重复来源对照**：重复申报和同项目取最高按组展示，保留项与所有不叠加项同屏对照，列出每份文件、工作表、行号、日期、原分值和实际计入情况。即使独立表填了时间而汇总表留空，也能查看同项目关系；普通明细中所有关联项都有对照入口，可导出完整对照表。
- **重复组快速审核**：确认采纳一条后，提示选择“作废其余”或“继续逐条审核”。整组作废在同一事务完成，保留原始记录及每条作废日志；已处理组仍可检索。记录身份、范围或分值尚未解决时，不能以整组作废绕过审核。
- **规则计算**：学术、文体科技、志愿、学生干部、荣誉、实践、论文作品、献血和处罚；奖项/级别/集体折算，分类上限、同项目最高分、年度次数及奖励/处罚分别封顶。
- **审核临时库**：差异、身份冲突、未知奖项、时长重叠和特殊项目集中提示。可采用原值、规则值、自定义值或排除，必须填写审核人和依据。待审核暂不计分。
- **汇总及基础分**：展示取最高、去重、封顶原因；可输入百分制教师分、学生评分、智育加权均分、体育成绩，按 10% + 10% + 70% + 10% 计算。未填完整不生成总分，不以零替代缺失。
- **汇总筛选与返回**：学生汇总支持班级、附加分类别和状态筛选；指定类别后显示本类申报数、分值及待审核数，总附加分仍单独保留。学生明细和单条申报均提供固定返回入口，返回时保留当前列表筛选。
- **历史库**：范围内待审核清零后归档，锁定申报、成绩、名册与设置。快照包含结果、原记录、全部审核日志和规则说明，生成 SHA-256 摘要；数据库触发器禁止更新/删除快照和日志。
- **更正流程**：填写原因创建修订版，再审核和归档，旧快照保持不变。
- **导出与备份**：Excel/WPS 可打开的 UTF-8 BOM CSV 汇总/明细；只读历史版查看与导出；完整 SQLite 在线备份，包含临时库、全部历史版本和主数据。

## 计算口径

详见 [docs/rules.md](docs/rules.md)。自动核算以提交表已获活动认定为前提。原值与规则不符、未知项目默认待审核，不直接覆盖。

同项目按项目名精确归组；可用“项目归并名称”统一跨级别/不同写法。不会模糊合并相似赛事；不同独立项目若共用宽泛标题，审核人需拆分名称。

志愿年度汇总与明细同时存在时须核对重叠。干部采用组织实评分值，不按上限加满，明显超出可识别岗位上限时提示审核。

暑期实践采用每人标准，不再次集体减半；寒假审批分值最高 0.4；同一假期取一项。学年依提交表所属批次，系统不凭模糊日期自动迁移学年。体育名次缺少前六/前八名赛制时人工核定。

裁判、表演（含主持）、活动经理各选最高两次，是本版明确采用的试算选取方式；办法只规定次数，正式使用时需确认单位口径。完全相同项目、身份、奖项、级别、集体属性、原分值、日期及归并名的条目去重；同名活动实际多次发生时，应补充不同名称或归并名称。

明细“计入”是分类封顶后的分值，总奖励另封顶 10 分，因此明细之和可能大于最终奖励分。学生详情同时显示封顶前后合计。

## 数据与恢复

- 默认数据库 `.local/assessment.sqlite3`。本地资料和数据库均被 Git 忽略，不纳入代码。
- 在“历史归档 → 完整数据库备份”下载一致备份，包含运行期间的 WAL 数据，避免运行中仅复制主文件导致遗漏。
- 恢复前停止服务，将备份复制到 `.local/`，用 `bash start.sh --db .local/备份.sqlite3 --no-seed` 启动。网页暂不提供覆盖恢复。
- 本版为本机单用户试用版，仅监听 `127.0.0.1`；审核人填写姓名，没有统一身份认证或多人权限。归档锁定是应用与 SQLite 约束，并非数据库管理员无法改动的独立可信存证。正式校园多人使用需另接身份与权限管理。
- 原办法 PDF 从桌面原路径读取，移机时需保留路径或调整 `app.py` 的 `POLICY`。

## 验证与代码

```bash
bash test.sh
```

测试覆盖计分边界、分组、去重、身份、缺失/零、手动类别匹配、导入事务、不可变归档、修订版和主数据约束，使用独立临时数据库，不改真实申报。

`app.py` 是本机服务/数据库/归档，`scoring.py` 是计分引擎，`importer.py` 读取 Excel，`registry.py` 维护主数据，`static/` 为网页，`tests/` 为测试。

当前工作区仍有待审核项，试算汇总不是正式测评结果。

工作区设置支持编辑学年（如 2025-2026），修改只更新当前批次标识，不会清空或切换批次。院系所固定字典存放在 `departments.json`，预置用户提供的 85 项代码及名称，按代码数字升序提供搜索和选择；页面及维护接口不允许新增、编辑或停用院系所。数据库中的 departments 表仅保留关联用的内部编号和历史记录，班级关联不删除。需要调整固定字典时修改文件并重启服务。归档保存当时学年和字典快照。

学生名册导入：基础信息维护 → 导入学生名册，支持 .xlsx 独立名册或附加分工作簿，也可从系统已导入申报提取。自动识别学号、姓名/学生、院系/学院/院系所、班级等表头及院系代码，不要求工作表类别匹配。先预览并勾选，再写入名册；重复且一致的人员合并，信息冲突/缺失/院系未匹配的条目显示来源并跳过，已有名册不覆盖。新班级自动建立，操作及来源留痕；不新增附加分申报、不更改分值。

实时试算：申报审核、新增申报、基础成绩编辑均随输入更新计算结果。试算复用正式计算规则，并考虑现有申报、重复归并和分类上限；顶部显示计算过程，审核底部显示实时分值。请求结果按最新输入显示，关闭窗口不会写入；点击保存才记录数据和审核日志。归档只读。

## 项目与学院名册

“项目管理”支持新建、打开、改名、导出项目包（JSON）、导入独立副本、删除及恢复。原有数据库保留为第一个项目；其他项目各有独立数据库，浏览器标签页分别记录当前项目。删除只移入回收站，不抹除归档。项目包包含申报原始值与当前值、基础成绩、文件来源、项目名册、审核日志和归档快照，不包含原 Excel/PDF 文件。

“本学院名册”是日常公共名册，默认按当前项目学院筛选；可新增/编辑班级与学生，导入 Excel 或从当前项目申报提取人员。“基础信息维护”是当前项目的名册副本，新建项目可复制公共名册；“从学院名册补充”仅补入缺失人员，冲突不覆盖。公共名册后续变更不影响已有项目或历史归档。首次启用时，将原有院系、班级和学生名册复制到公共名册。

两处名册页面支持院系、班级、启用状态、文字搜索筛选，勾选或跨页全选筛选结果，批量调班、启用、停用学生，以及批量启用/停用班级。变更筛选条件会清空勾选，确认前显示数量。批量操作留痕，任一条不满足条件时整批撤回。

本地完整备份应保存整个 `.local` 目录（含 `assessment.sqlite3`、`projects-catalog.sqlite3` 和 `projects/`）。网页已有 SQLite 备份只对应当前项目；跨项目迁移请逐个导出项目包，公共名册单独保留目录备份。


### 名册回收站与班级别名

- 在“基础信息维护”或“本学院名册”中勾选班级/学生，使用“批量维护 → 删除到回收站”。两处名册的回收站相互独立，可批量恢复；永久删除需核对名单并输入确认文字。已有申报的学生不能删除，班级下仍有学生时不能永久删除。恢复学生前须先恢复并启用所属班级。
- 班级编辑中的别名支持中文、英文逗号分隔，同院系内不能与其他班级名称或别名重名。名册导入预览及当前申报计算会匹配标准班名，原始申报和历史快照保持不变。
- 项目回收站可手动永久删除，需输入项目名称确认；启动时清理已删除超过 30 天的项目。默认项目仅支持恢复，不执行永久删除或超期清理。文件删除失败时保留回收站条目供重试。
- 汇总式工作表可选择按每行类别识别，未知类别进入待审核；也可统一指定工作表类别或跳过该表。旧版项目包缺少新增名册字段时自动补齐默认值。
